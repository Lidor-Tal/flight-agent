# 🛫 סוכן טיסות — מדריך הפעלה צעד-צעד

סוכן שרץ במחשב שלך, בודק טיסות TLV ⇄ KGS, ושולח לך הודעה בטלגרם
כשמופיעה טיסת צהריים במחיר טוב.

> ℹ️ **מקור הנתונים:** הסוכן משתמש ב-SerpApi (Google Flights) — נתונים
> אמיתיים בזמן אמת כולל שעות מדויקות. יש **100 חיפושים חינם בחודש**,
> מספיק בהחלט לסוכן שרץ כמה פעמים ביום.

---

## שלב 0 — להתקין את הכלים (פעם אחת)

1. **Node.js** — הורד מ-https://nodejs.org (גרסת LTS). זה מה שמריץ את הקוד.
   לבדיקה שהותקן, פתח טרמינל והקלד: `node -v` — אמור להופיע מספר גרסה.
2. **VS Code** — הורד מ-https://code.visualstudio.com (אתה כבר משתמש בו).

---

## שלב 1 — לפתוח את הפרויקט

1. פתח את התיקייה `flight-agent` ב-VS Code
   (`File → Open Folder → בחר את flight-agent`).
2. פתח טרמינל בתוך VS Code: תפריט `Terminal → New Terminal`.

---

## שלב 2 — להתקין את הספריות

בטרמינל שנפתח, הקלד:

```bash
npm install
```

זה מוריד את כל מה שהפרויקט צריך (לוקח דקה). תיווצר תיקיית `node_modules`.

---

## שלב 3 — להשיג מפתח SerpApi (נתוני הטיסות)

1. הירשם חינם ב-https://serpapi.com/users/sign_up (מייל + סיסמה, בלי כרטיס אשראי)
2. אמת את המייל.
3. היכנס ל-https://serpapi.com/manage-api-key והעתק את ה-**API Key** שלך.
   זה הערך שתשים ב-`SERPAPI_KEY` בקובץ ה-.env.

---

## שלב 4 — ליצור בוט טלגרם

1. בטלגרם, חפש את **@BotFather** ולחץ Start.
2. שלח `/newbot`, תן לו שם, ושם משתמש שמסתיים ב-`bot`.
3. BotFather יחזיר לך **טוקן** (משהו כמו `123456:ABC-xyz...`). שמור אותו.
4. **חשוב:** שלח הודעה כלשהי לבוט שיצרת (כל מילה), אחרת הוא לא יוכל
   לכתוב לך בחזרה.

### איך משיגים את ה-Chat ID שלך:
פתח בדפדפן את הכתובת הזו (החלף את `TOKEN` בטוקן שקיבלת):

```
https://api.telegram.org/botTOKEN/getUpdates
```

חפש בתשובה את `"chat":{"id":123456789` — המספר הזה הוא ה-`TELEGRAM_CHAT_ID`.

---

## שלב 5 — למלא את הסודות

1. שכפל את הקובץ `.env.example` וקרא לעותק `.env` (בלי ה-`.example`).
   בטרמינל: `cp .env.example .env`
2. פתח את `.env` ב-VS Code ומלא את כל הערכים שאספת בשלבים 3-4.
3. אפשר גם לשנות את התאריכים, חלון השעות והמחיר המקסימלי כרצונך.

---

## שלב 6 — להריץ! 🚀

בטרמינל:

```bash
npm start
```

מה שיקרה:
- הסוכן יתחבר, יחפש טיסות, יסנן לפי הקריטריונים שלך,
- ואם ימצא טיסה מתאימה — תקבל הודעה בטלגרם תוך שניות.
- אם אין מתאימה — יודיע בטרמינל ולא ישלח כלום.

---

## שלב 7 — שיֵרוץ אוטומטית (אחרי שזה עובד)

ההרצה למעלה היא חד-פעמית. כדי שירוץ **לבד כל כמה שעות**, יש 2 דרכים:

**א. פשוט — לתזמן במחשב שלך:**
- Windows: Task Scheduler
- Mac/Linux: cron

**ב. מקצועי (מומלץ לך) — GitHub Actions:**
- מעלים את הפרויקט ל-GitHub (כמו שאתה כבר עושה ב-TechLead AI),
- מוסיפים קובץ `.github/workflows/check.yml` עם `schedule`,
- שמים את הסודות ב-GitHub Secrets (לא ב-.env הציבורי!).
- זה ירוץ בענן בחינם, בלי שהמחשב שלך יהיה דלוק.

תגיד לי כשתגיע לשלב הזה ואכין לך גם את ה-workflow.

## בעיות נפוצות

| בעיה | פתרון |
|------|--------|
| `command not found: npm` | Node.js לא הותקן — חזור לשלב 0 |
| `SerpApi failed: 401` | המפתח ב-.env שגוי |
| `SerpApi failed: 429` | נגמרו 100 החיפושים החינמיים החודש |
| לא מגיעה הודעת טלגרם | שכחת לשלוח הודעה ראשונה לבוט (שלב 4.4) |
| `אין טיסה מתאימה` תמיד | נסה להעלות MAX_PRICE_EUR או להרחיב את חלון השעות |
